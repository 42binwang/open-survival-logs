# WP-P0-01 — Build, interfaces and gate skeleton (architect)

**Role:** architect. **Phase:** P0. **Depends on:** nothing.

## Scope
- `package.json` + lockfile with scripts `dev`, `build`, `preview`, `test` (runs the existing `node --test tests/*.test.js`
  unchanged), `typecheck` (`tsc --noEmit --checkJs` over files carrying `// @ts-check`), `lint` (ESLint flat config),
  `e2e` (Playwright), `gate` (`node tools/gate.mjs`).
- Vite serving and building the existing game (index.html → src/main.js) with no behavior change; three.js,
  Playwright (Chromium installed), ESLint, TypeScript as dev/runtime deps; `@gltf-transform/cli` and
  `@gltf-transform/functions` + `meshoptimizer` for the model pipeline.
- `.gitattributes` for git LFS (`*.glb *.gltf *.bin *.ktx2 *.ogg *.opus *.wav *.flac *.hdr *.exr *.png *.jpg` under
  `assets/`), `.gitignore` (`node_modules/`, `dist/`, `assets/cache/`, `test-results/`, `playwright-report/`),
  `git lfs install` for the repo.
- README: what this is, how to run, and that it is a private, non-distributed build that must not be published.
- `.cursor/rules/project.mdc` (alwaysApply): ownership, key-registry, test and gate rules, pointer to `docs/wp/README.md`.
- Interfaces (frozen for P0, in `src/contracts/`, each `// @ts-check` with JSDoc types):
  - `view.js` — the view-model typedef the Canvas renderer consumes today (`src/ui/view.js` homeView and the shop /
    explore views): floor grid, furniture, entities, boxes, clock, weather, lights, basement, flashlight, fires,
    slots, `locked()`, `roomAt()`; room to extend.
  - `render.js` — the renderer interface both renderers implement: construct with a canvas, `draw(view)`,
    `pick(view, wx, wy)`, `toWorld(cx, cy)`, `toCanvas(x, y)`, `cam`, `highlight`, `lightning()`, `resize()`.
  - `assets.js` — the asset-manifest schema (id, kind, path, LOD, variants, license id).
  - A renderer switch in `src/main.js`: `?render=2d` keeps `src/render/iso.js`; the default stays 2D until the
    3D renderer is ready (the switch reads a registry so `src/render3d/` can plug in later).
- `tools/gate.mjs`: a check registry with `--quick`, `--status`, `--signoff P{n}` and `--final`. Checks: tests,
  typecheck, lint, coverage, keys-audit, determinism (two seeded headless runs hash-equal), Playwright UI, visual
  regression, art metrics, budgets, asset lock. Checks that are not built yet report `pending` (a failure for
  `--final` and for any `--signoff` that requires them). `--status` prints phase, check states and ledgers.
- Playwright smoke test: title screen → New Game → the apartment renders; screenshot.

## Exclusive paths
`package.json`, `package-lock.json`, `vite.config.*`, `tsconfig.json`, `eslint.config.*`, `playwright.config.*`,
`.gitattributes`, `.gitignore`, `README.md`, `.cursor/rules/`, `src/contracts/view.js`, `src/contracts/render.js`,
`src/contracts/assets.js`, `tools/gate.mjs`, `tools/gate/`, `tests/e2e/`, and the renderer switch lines in `src/main.js`.
