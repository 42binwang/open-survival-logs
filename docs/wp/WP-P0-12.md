# WP-P0-12 — Icon rig spike

**Role:** icons lane. **Phase:** P0. **Depends on:** Blender; WP-P0-05 materials; WP-P0-14 (rebuild contract; the
manifest adopts it when it lands).

## Scope
- One fixed Cycles icon rig (`tools/blender/icons/`): camera, three-point lighting, backdrop-free alpha, 256² denoised,
  downsampled to 64 and 128; a quality badge overlay for tiers.
- Parametric containers with label art made for this game (cans, jars, bottles, boxes, bags, packets) and a dish
  template (bowl, plate, pot) with food material variants.
- Render the icons the UI tile needs: canned luncheon meat, instant noodles, bread, rice, a bottle of water, first-aid
  bandage, planks, a cooked dish in two qualities, a seed packet, a trap, a book / note — as `assets/icons/<id>.png`
  (64/128/256) + `assets/icons/manifest.json` keyed by config item id.
- The manifest follows WP-P0-14's rebuild contract: a `rebuild` recipe for the rig with `cycles { seed, samples }`,
  pinned tools and `cost`, and on every entry its recipe name and the SHA-256 `digests` of each shipped file.

## Exclusive paths
`tools/blender/icons/`, `assets/icons/`, `docs/art/icons/`, `assets/lock/WP-P0-12.json`, `assets/credits/WP-P0-12.md`,
`tests/icons.test.js`.

## Read
Everything.

## Acceptance
- Every icon exists at 64/128/256 with alpha; icons in a category are perceptually distinct (hash distance check);
  no text artifacts on labels.

## Deliverables
Rig, builders, icons, manifest, the JSON report.
