# WP-P0-03 — Coverage tool (architect)

**Role:** architect. **Phase:** P0. **Depends on:** nothing (plain Node). Immutable after P0 except for
demonstrated-bug fixes approved by a reviewer.

## Scope
`tools/coverage.mjs` reads `src/data/gen` for its denominators (never a list we wrote) and checks every entity with
an automated probe that drives the real sim headless:
- **items:** obtainable (shop stock, loot tables, craft output, harvest, cooking output, event / people rewards,
  starter kits) and usable as the config says (eat / use / read / open / install / fuel / seed / bait / material).
- **furniture:** obtainable and installable in a valid slot of some home; rendered with its own model or a family
  model plus a variant (reads the asset manifest — none yet, so this family reports its real, low number); every
  config function works (spec present and the action completes) or is shown to be unreachable for that character.
- **recipes:** every cooking recipe and every crafting recipe runs end to end in the sim and yields its config outputs.
- **plants:** every plant can be planted and grown to harvest under its config conditions.
- **furniture functions:** every function id has a spec (`src/content/funcSpecs.js` or a registered kind) and a test.
- **achievements:** every achievement is earnable, with a test that earns it (map achievement id → test name).
- **patch notes:** every line item in `https://store.steampowered.com/news/app/4164790` maps to a `docs/FEATURES.md` row or is marked not
  applicable with a reason (`docs/coverage/news-map.json`).

Output: a per-family table and total percentage on stdout, `--json` for the gate, failures listed with the entity id
and the probe that failed. Rows reopen in FEATURES.md when a probe finds a gap (report them; the integrator edits
the ledger).

## Exclusive paths
`tools/coverage.mjs`, `tools/coverage/`, `docs/coverage/`, `tests/coverage-tool.test.js`.

## Read
Everything.

## Acceptance
- `node tools/coverage.mjs` runs in ≤ 5 minutes and prints the table; its own tests pass.
- Every probe is exercised by at least one passing and one failing fixture in `tests/coverage-tool.test.js`.
- The existing suite stays green.

## Deliverables
The tool, the news map, the first coverage report (`docs/coverage/P0.md`), the JSON report with the gap list.
