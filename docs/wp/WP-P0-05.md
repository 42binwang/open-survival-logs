# WP-P0-05 — Asset pipeline and scanned material library

**Role:** art lane (materials) + pipeline. **Phase:** P0. **Depends on:** nothing to start (Blender and ffmpeg are
installed system-wide by the coordinator); read `docs/ART.md` from WP-P0-04 when it lands for texel density.

## Scope
- **Toolchain:** KTX-Software command-line tools (no Homebrew formula: use the official GitHub release for macOS arm64,
  unpacked into `tools/bin/` by a script, version pinned); gltf-transform + meshopt (request the npm devDependencies
  from the architect as a hook request, and use `npx` meanwhile). Headless Blender entry point
  `tools/blender/run.sh <script.py> [args]`.
- **Fetch and lock:** `tools/fetch-assets.mjs` restores `assets/cache/` from the lockfile (download, verify SHA-256,
  unpack) and adds new sources (`--add <url> --license ...`). Writes `assets/lock/WP-P0-05.json` and
  `assets/credits/WP-P0-05.md` fragments (URL, license, SHA-256, author, what it is used for).
- **Material library** (`tools/materials/` graph + `tools/blender/materials/`): 2K CC0 scans from ambientCG / Poly Haven
  for the spike room — painted plaster, wallpaper, wood floor (two species), ceramic tile, grout, concrete, fabric
  (sofa, curtain), leather, laminate, brushed and painted metal, glass, rubber, cardboard — calibrated to the value
  bands, with large-scale variation masks, curvature / cavity wear, gravity dirt and per-instance tint parameters.
  Shipped as KTX2: UASTC normals; ETC1S albedo and packed AO/roughness/metallic; 1K hero, 512 elsewhere.
  Output `assets/materials/<name>/` + `assets/materials/library.json` (the material manifest the renderer reads).
- **Objective checks** for materials (feed tools/art-metrics.mjs later): PBR validity (albedo range, roughness not
  saturated, unit normals), seamless tiling, texel density.

## Exclusive paths
`tools/bin/`, `tools/blender/run.sh`, `tools/blender/common/`, `tools/blender/materials/`, `tools/materials/`,
`tools/fetch-assets.mjs`, `assets/materials/`, `docs/art/materials/`, `assets/lock/WP-P0-05.json`,
`assets/credits/WP-P0-05.md`, `tests/materials.test.js`.

## Read
Everything.

## Acceptance
- `node tools/fetch-assets.mjs --verify` restores and verifies every locked source into `assets/cache/`.
- Every material in `library.json` passes the PBR-validity, tiling and size checks (`tests/materials.test.js`).
- A Blender preview render of each material on a sphere and a wall patch (`docs/art/materials/*.png`).

## Deliverables
Pipeline scripts, the material library, the lock and credit fragments, the JSON report.
