# WP-P0-07 — UI style tile and docs/UI.md (best-of-2)

**Role:** UI lane; two competing builders, the reviewer picks one. **Phase:** P0.
**Depends on:** WP-P0-01 (Vite), WP-P0-04 (ART.md palette), WP-P0-12 (rendered icons).

## Scope
- `docs/UI.md`: the UI kit — type scale, 4 px grid, color tokens and type sizes (the 12 measured tokens and the type heights in ART.md §8), panels, buttons (primary, secondary,
  danger, disabled), tooltips, inventory slots (sizes 1×1 … 3×3, rotation, badges for servings / quality / expired),
  progress bars, toasts, modals, motion tokens (durations, easings), focus and hover states, EN/ZH typography.
- The kit as CSS tokens and components (`src/ui/kit/`), not yet applied to the game panels.
- `pages/ui-tile.html`: the style tile showing the inventory (backpack + storage), a shop window and the HUD (top bar,
  stats, objectives, toolbar) in the final kit, with the rendered icons from WP-P0-12, at 1920×1080 over a still of
  the tech-spike room.

## Exclusive paths
`docs/UI.md`, `src/ui/kit/`, `pages/ui-tile.html`, `pages/ui-tile/`, `tests/e2e/ui-tile.spec.*`.
