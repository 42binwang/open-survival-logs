This is the authoritative list of features of **Survival Log** (Midnight Workshop / Lilith Games, Steam app 4164790,
released 2026-08-12, version 1.0.16756 as of the 2026-09-17 patch) that this browser recreation must cover.

Every row gets a status, a pointer to the code that implements it, and a pointer to the test that exercises it.

**Status legend:** ⬜ not started · 🟨 partial · ✅ implemented and covered by a test. A row that was ✅ and is **reopened** on a coverage gap is 🟨, and its last cell ends with the gap (docs/coverage/P0.md: each family / check and its failing entities)

**Source keys** (full list in [`SOURCES.md`](./SOURCES.md)):

- `S` Steam store page · `N:MM-DD` official Steam news post of that date (2025-11 … 2026-09) · `DL#` dev logs
- `A:<id>` achievement config / Steam achievement · `G1` "100% Achievements + End Game" guide · `G2` endings guide (CN)
- `G3` 100-day survival guide (CN) · `G4` IndieBunny early-game guide · `G5` 18183 character guide · `G6` talent guide (12365)
